INF2005 Audio Steganography

Hide a signed message in PCM WAV audio and check it for tampering.

For a listening comparison, use 16-bit audio and 1–2 LSBs. Higher settings, especially with 8-bit audio, may add audible noise.

1. Embed

The start location is derived automatically using the shared secret and a fresh nonce.

Cover

Stego

Audio uses the same saved signing key and start-location secret as the image workflow. Another instance needs the trusted public key, matching LSB setting, and the same configured start-location secret. The start index is recovered automatically. The message is hidden, not encrypted. Older audio stego files must be embedded again.
