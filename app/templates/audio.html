INF2005 Audio Steganography

Hide a signed message in PCM WAV audio and check it for tampering.

For a listening comparison, use 16-bit audio and 1–2 LSBs. Higher settings, especially with 8-bit audio, may add audible noise.

Embed Payload

Upload a WAV to see its capacity in bits.

The start location is derived automatically using the shared secret and a fresh nonce.

Enter a message to see its payload size.

Small: up to 150 characters; Medium: 151–499; Large: 500 or more. Payload includes metadata and signature. Capacity accounts for the start-location header, authentication tag and padding.

Audio uses the same saved signing key and start-location secret as the image workflow. Another instance needs the trusted public key, matching LSB setting, and the same configured start-location secret. The start index is recovered automatically. The message is hidden, not encrypted. Older audio stego files must be embedded again.

Demo Utility: Generate "Tampered" Test File

  
Upload your stego WAV to deliberately change one audio sample and demonstrate the Tampered verdict. For this demo, use a valid 16-, 24-, or 32-bit PCM stego WAV so the change leaves the hidden payload intact. Your original file is unchanged.

  

    
    
  

  

  
Download the generated file, then upload it under Verify Stego Audio using the original LSB count and matching public key, leaving the optional start index blank. Expected verdict: Tampered. Damage to the hidden packet in 8-bit audio may produce a different failure verdict.





  
Demo Utility: Generate "Cannot Verify" Test File

  
This creates a fresh sample WAV, embeds a signed payload, then deliberately breaks the hidden JSON while keeping the SL02 header intact and recomputing its payload HMAC with the server secret. The app can find the packet but cannot process its contents, demonstrating the Cannot Verify verdict. No upload is needed.

  

    
  

  

  
Download the generated file, then upload it under Verify Stego Audio with 1 LSB and leave the optional start index blank. Leave the public-key field empty. Expected verdict: Cannot Verify.





  
Demo Utility: Generate Wrong Public Key

  
Generate a separate valid RSA public key to demonstrate the Signature Invalid verdict. No upload is needed. The server's signing keys remain unchanged.

  

    
  

  

  
Download wrong-public-key.pem. Under Verify Stego Audio, upload your valid stego WAV and select this file as the Signer's Public Key. Use the correct original LSB count and leave the optional start index blank. Expected verdict: Signature Invalid. Afterwards, clear this key selection to use the server's default key, or upload the matching key.
