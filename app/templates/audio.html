INF2005 Audio Steganography

Hide a signed message in PCM WAV audio and check it for tampering.

For a listening comparison, use 16-bit audio and 1–2 LSBs. Higher settings, especially with 8-bit audio, may add audible noise.

1. Embed

Cover

Stego

Audio uses the same saved signing key as the image workflow. Download the public key for verification on another instance and share the bit setting and start sample with the recipient. The message is hidden, not encrypted.

2. Extract and verify

Leave the public key empty to use the server's default key.






  
Demo Utility: Generate "Tampered" Test File

  
Upload your stego WAV to deliberately change one audio sample and demonstrate the Tampered verdict. For this demo, use a valid 16-, 24-, or 32-bit PCM stego WAV so the change leaves the hidden payload intact. Your original file is unchanged.

  

    
    
  

  

  
Download the generated file, then upload it under Extract and verify using the original LSB count, start sample, and matching public key. Expected verdict: Tampered. Damage to the hidden packet in 8-bit audio may produce a different failure verdict.





  
Demo Utility: Generate "Cannot Verify" Test File

  
This creates a fresh sample WAV, embeds a signed payload, then deliberately breaks the hidden JSON while keeping the packet header intact. The app can find the packet but cannot process its contents, demonstrating the Cannot Verify verdict. No upload is needed.

  

    
  

  

  
Download the generated file, then upload it under Extract and verify with 1 LSB and start sample 100. Leave the public-key field empty. Expected verdict: Cannot Verify.





  
Demo Utility: Generate Wrong Public Key

  
Generate a separate valid RSA public key to demonstrate the Signature Invalid verdict. No upload is needed. The server's signing keys remain unchanged.

  

    
  

  

  
Download wrong-public-key.pem. Under Extract and verify, upload your valid stego WAV and select this file as the Trusted public key. Use the correct original LSB count and start sample. Expected verdict: Signature Invalid. Afterwards, clear this key selection to use the server's default key, or upload the matching key.
